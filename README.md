# Cara Menjalankan Project NutriNesia

## Persiapan
Pastikan device yang digunakan untuk testing sudah terhubung ke koneksi internet.

## Langkah-Langkah

### 1. Clone Repository
Clone repository NutriNesia:

```bash
git clone https://github.com/ayuarista/004_Komang-Ayu-Arista-Dewi_NutriNesia
````
### 2. Buka Project di IDE

Buka folder project menggunakan IDE favorit kalian, seperti:

* Visual Studio Code
* Sublime Text
* IntelliJ IDEA
* dan lainnya

### 3. Install Extension Live Server

Jika menggunakan Visual Studio Code:

* Buka menu **Extensions**
* Cari **Live Server**
* Install extension tersebut

### 4. Jalankan Website

Setelah extension terinstall:

* Klik tombol **“Go Live”** di pojok kanan bawah Visual Studio Code
