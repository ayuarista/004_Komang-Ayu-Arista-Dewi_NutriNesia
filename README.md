# Judul Website: NutriNesia
# Deskripsi singkat: 
NutriNesia adalah platform kesehatan dan nutrisi untuk membantu masyarakat Indonesia memahami pola makan, memantau asupan harian, serta membangun gaya hidup sehat yang lebih terarah dan berkelanjutan. Melalui fitur analisis gizi, perencanaan nutrisi, resep sehat, challenge sehat, konsultasi gratis, hingga komunitas aktif, NutriNesia hadir sebagai pendamping digital untuk membantu pengguna mencapai target kesehatan mereka dengan cara yang lebih mudah, modern, dan menyenangkan.
# Teknologi yang digunakan
* HTML
* CSS
* JAVASCRIPT

# Cara Menjalankan Project NutriNesia

## Persiapan
Pastikan device yang digunakan untuk testing sudah terhubung ke koneksi internet.

## Langkah-Langkah

### 1. Clone Repository
Clone repository NutriNesia:

```bash
git clone https://github.com/ayuarista/004_Komang-Ayu-Arista-Dewi_NutriNesia
````
### 2. Buka Project di IDE

Buka folder project menggunakan IDE favorit kalian, seperti:

* Visual Studio Code
* Sublime Text
* IntelliJ IDEA
* dan lainnya

### 3. Install Extension Live Server

Jika menggunakan Visual Studio Code:

* Buka menu **Extensions**
* Cari **Live Server**
* Install extension tersebut

### 4. Jalankan Website

Setelah extension terinstall:

* Klik tombol **“Go Live”** di pojok kanan bawah Visual Studio Code
